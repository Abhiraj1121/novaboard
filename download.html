Windows Recommended

Setup installer for Windows 10 and 11, 64-bit. Adds Desktop and Start Menu shortcuts.

NovaBoard-OS-Setup-v3.0.2.exe

Download .exe
How to install
  1. Run NovaBoard-OS-Setup-v3.0.2.exe.
  2. If Windows shows Windows protected your PC, select More info, then Run anyway. The installer is not code-signed yet, so Windows lists the publisher as unknown.
  3. Follow the wizard: accept the license, choose a folder and finish.
  4. Tick Launch NovaBoard OS on the last page to start the app.

Debian, Ubuntu and Mint Recommended

Package for 64-bit Debian-based systems. Installs to the app menu.

NovaBoard-OS-v3.0.2-amd64.deb

Download .deb
How to install
  1. Open a terminal in the folder with the file and run:
    sudo apt install ./NovaBoard-OS-v3.0.2-amd64.deb
  2. Launch NovaBoard OS from your app menu.
  3. To remove it later:
    sudo apt remove novaboard-os

Any Linux Recommended

Portable AppImage for 64-bit distributions. No install needed.

NovaBoard-OS-3.0.2-x86_64.AppImage

Download AppImage
How to run
  1. Make the file executable and start it:
    chmod +x NovaBoard-OS-3.0.2-x86_64.AppImage && ./NovaBoard-OS-3.0.2-x86_64.AppImage
  2. On Ubuntu 22.04 and newer you may also need FUSE:
    sudo apt install libfuse2
  3. If it will not start because of sandbox restrictions, run it with --no-sandbox.

Android Recommended

APK for Android phones and tablets.

NovaBoard-OS-v3.0.2.apk

Download .apk
How to install
  1. Download the file on your Android device and open it.
  2. If Android asks, allow installing apps from your browser or file manager, then continue.
  3. Open NovaBoard OS from your app drawer.

Good to know

Smartboard mode

On Linux, start fullscreen with novaboard-os --fullscreen. On Windows, add --fullscreen to the shortcut's target.

Offline, with two exceptions

Drawing, pages, PDFs and tools work without a connection. The AI Assistant and Live Share need internet.

Updates keep your boards

Boards are auto-saved inside the app's own data folder, so updating or reinstalling does not remove them. Save a .novaboard file for a backup.

Prefer not to install anything?

NovaBoard OS runs in any modern browser with no account.
